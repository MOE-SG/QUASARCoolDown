Paste data

Copy the rows in the logging application and paste them here (Ctrl+V, or long-press and Paste on a phone). A header row is optional: without one, the standard QADR/COMRES column order is used. Rows with empty cells missing on the left are padded so the columns line up.

Scale sets

A scale set holds the default vertical range of every chart. "Reset" on a chart, double-click, and "Reset all" go back to the selected set. Built-in sets are read-only; save a copy to change them. Leave min and max empty to auto-fit that chart.
